P2-R 实际运行库最初为 V1 且无用户、题库或学习记录；在线备份验证通过后迁移到 V3 并创建四个普通账号。该运行库尚未初始化应用内管理员，也没有题库；P2-R 未导入 Excel。临时初始密码只留在权限为 `0600` 的本机凭据文件中。完整剩余安全事项继续保留在 GitHub Issue #3。

P3 使用临时 SQLite 和本地 Excel 完成 1,283 题导入、180 题组卷、判分及浏览器验收。检查本机数据库状态时 db:status 通过 openDatabase() 自动应用了增量 V4 迁移；四个普通账号保留，管理员数和题库数仍为 0，未导入正式题库。当前本机服务运行 P3 构建，公网、frp 与 APK 发布未开始。

P4 在隔离 SQLite 中新增 V5 复习轮次结构，并修复 `db:status` 只读路径。使用本机真实 Excel 导入 1,283 题（845 单选、38 多选、400 判断），浏览器验证普通练习错答入错题、组合筛选、题量不足提示、轮次恢复、两轮正确后掌握、历史与桌面/手机页面。正式数据库只读检查仍为 V4，四个普通账号保留，无管理员、无题库；未执行正式迁移或导入。Issue #6 在修复和只读回归验证后关闭；Issue #5 在 P4 全部验收及同步后关闭。

## 开发节奏
- **长期**（全周期）：稳定需求、架构与视觉质量基准，由 `docs/PRD-V1.md` / `memory/LONG_TERM.md` / `AGENTS.md` 维护。
- **中期**（里程碑）：在 `memory/MID_TERM.md` 中记录阶段状态、决策、依赖、风险、验收结果；变动需指明证据。
- **短期**（每轮会话）：在 `memory/SHORT_TERM.md` 中记录当前分支、已改文件、已执行命令、失败原因、下一条命令/任务。

## 版本冻结
- 优先让 P0-P4 跑通真实端到端，再做网络分发/美化收尾。
- 桌面首页基准在 P0 冻结为 V1；手机 12 页以已确认的手机效果图为独立基准。设计更改须先更新 `docs/UI_SPEC.md` 与参考资产，不能私下替换已确认的方向。
