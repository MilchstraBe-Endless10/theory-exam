# 测试与验收矩阵

## 必测
- Excel 1283 行，845 单选 / 38 多选 / 400 判断；选项及答案精确保留；缺失/错误行报告；重复题保留提示；重复导入不悄悄翻倍。
- 账号只能管理员创建；普通 APP 无注册按钮；禁用账号令会话失效；user A 不能访问 user B 的答题/成绩 API。
- 单选120×0.5=60，多选20×1=20，判断40×0.5=20，合计180题100分90分钟；每场同记录不重复；题型不足阻止开考。
- 考试开始后固定顺序/选项/答案快照；跨版本题库不影响旧成绩。
- 多选答案顺序不影响正确性，少选/多选/错选得0；未答得0且不等于用户实际答错。
- 交卷/超时重复请求幂等；服务端截止时刻权威；答案更新有顺序保护；超时不接收离线补交。
- 考试时 App 锁屏/切换/杀进程/断线/重连/服务器重启恢复已保存数据；持续计时不重置。
- 错题首次错进入待复习；第一独立轮次复习答对到巩固中；第二独立轮次连续答对到已掌握；中途再错归零；同轮重复不刷满进度。
- 混合与题型筛选、随机与薄弱优先、10/20/全部都能组合；题少自动缩减并提示。
- 局域网/公网入口切换保留同一会话；HTTPS 无效证书拒绝连接；管理 API 不能从外网普通入口访问。
- SQLite 备份/恢复具备实际演练；服务启动/停止/重启无损坏；敏感凭据不在日志和 Git 中。
- APP 390×844 与 360×800 显示完整；桌面 1536×1024 截图视觉验收。

## 证据格式
每项测试记录：测试标识｜执行日期｜执行命令/手动步骤｜观察到的结果｜通过/失败/阻塞｜日志/截图路径。不要只写「测试通过」而没有执行证据。
