# 理论考试练习系统 V1.0 产品需求说明书

**项目版本：** V1.0  
**项目状态：** 需求规划完成，待实施  
**部署形式：** 本机 Linux 服务端 + Android APP  
**网络方案：** 局域网直连 + 现有 frp 内网穿透  
**代码及安装包发布：** GitHub

## 一、项目概述

开发一个面向少量用户使用的理论考试学习系统。用户通过 Android APP 登录个人账号，进行日常刷题、模拟考试、错题复习和成绩查询。

系统由用户自己的 Linux 电脑提供全部业务服务，题库、账号、成绩和学习记录集中存储在本机，手机不承担长期数据存储职责。

系统不涉及商业化运营、复杂后台管理、AI 自动解析、排行榜或社交功能。

## 二、使用对象

系统设有两类使用入口：

- **本机维护端：** 创建账号、导入题库、配置考试规则、备份与恢复数据、查看运行状态。
- **普通用户端：** 登录、刷题、模拟考试、错题复习、收藏题目、查看个人学习记录与成绩。

普通账号由本机服务端统一创建，不允许自行注册。

不同账号的数据必须相互隔离，用户只能访问自己的学习记录。

## 三、题库导入

系统提供可见的「导入题库」按钮，首版支持 XLSX 格式。

以当前《四级理论试题.xlsx》为第一份正式题库，系统需要识别：

- 题型：单选、多选、判断
- 题干
- 选项 A、B、C、D、E
- 正确答案

当前 Excel 共 1,283 道题，其中单选题 845 道、多选题 38 道、判断题 400 道。

导入后应显示题量、题型统计、错误数据和重复题提示，确认后才正式写入数据库。

不能仅根据题干相同就自动合并题目。重复导入同一文件应提醒用户，避免产生整套重复题库。

题库采用独立管理结构，初期使用四级题库，后续允许导入三级以及其他职业考试题库。

不同题库可以配置各自的考试题量、分值和时长。

## 四、日常刷题

提供以下练习方式：

1. 顺序练习
2. 随机练习
3. 按单选、多选、判断题分类练习
4. 只练习尚未作答的题目
5. 收藏题目专项练习

练习时，用户提交答案后立即显示正确或错误，并展示标准答案。

没有解析的题目不生成虚假解析。

所有正式提交的作答都记录在服务端，支持退出后继续练习。

## 五、模拟考试

### 5.1 四级理论考试规则

| 题型 | 数量 | 每题分值 | 小计 |
|---|---:|---:|---:|
| 单选题 | 120 | 0.5 分 | 60 分 |
| 多选题 | 20 | 1 分 | 20 分 |
| 判断题 | 40 | 0.5 分 | 20 分 |
| **总计** | **180** | — | **100 分** |

考试时间固定为 **90 分钟**。

### 5.2 组卷

由服务端随机抽取指定数量的题目，同一场考试不重复使用同一条题目记录。

每场考试开始后必须保存固定试卷，不允许重新连接时重新组卷。

建议按单选、多选、判断分区展示，各题型内部随机排列。

### 5.3 考试操作

考试过程中支持：

- 倒计时
- 上一题、下一题
- 题号快速跳转
- 修改答案
- 标记待检查题目
- 查看已答与未答数量
- 提前交卷
- 到时自动交卷

考试过程中不显示正确答案。

交卷后统一评分。多选题默认完全选对才得分，不设部分分数；未作答题目计 0 分。

每次考试记录总分、题型得分、正确数、错误数、未作答数、考试时间和历史试卷。

## 六、错题复习

错题来源包括日常练习和模拟考试。

同一道题在同一用户的错题本中只占一条状态记录，但保留历史作答和错误次数。

### 6.1 掌握规则

题目首次答错后进入「待复习」。

第一次复习答对，进入「巩固中」。

在**另一轮复习中再次答对**，进入「已掌握」。

如果中途再次答错，连续正确次数清零，重新进入「待复习」。

已经掌握的题目不删除；未来再次答错时重新加入待复习列表。

### 6.2 复习方式

支持三类可组合配置：

- 题型：全部混合、仅单选、仅多选、仅判断
- 顺序：随机抽题、薄弱题优先
- 数量：10 道、20 道、全部

薄弱题优先考虑掌握状态和历史错误次数。

每道题在同一轮复习中只能贡献一次有效掌握进度。

不同题库与不同用户的错题记录独立。

## 七、网络连接

本机作为服务端，使用现有 frp 提供外网访问。

局域网环境直接访问本机服务；外网通过公网入口、frps、frpc 转发到本机。

优先使用可信 HTTPS 连接。APP 支持首次扫码绑定服务器，也可手动输入地址。

APP 应在局域网和外网连接之间自动切换，切换时保留用户身份及正在进行的考试状态。

管理功能不通过公网穿透入口发布。

## 八、考试中断恢复

以服务器时间为考试计时标准。

手机锁屏、切换应用、网络中断或 APP 关闭时，考试继续计时，不重新开始。

每次修改答案时进行临时保存与服务器同步，并显示：

- 已同步
- 等待同步
- 连接中断

服务端确认收到的答案才算正式保存。

用户重新连接后恢复同一场考试及其剩余时间。

超过考试截止时间后，不接受普通离线答案补交；服务器按已确认答案结算。

服务端重启后，需要恢复进行中的考试与原试卷。重复交卷不得产生重复成绩。

## 九、用户账号

管理员从本机管理端创建用户名及初始密码。

普通用户只能登录，不能注册其他账号。

支持用户修改个人密码、保持登录和退出登录。

管理员可以重置密码、启用或禁用账号。

密码使用安全哈希保存，接口必须验证身份和数据访问权限。

## 十、学习记录

用户可以查看：

- 当前题库的已做和未做题目
- 各题型正确率
- 错题数量与掌握状态
- 历史考试成绩
- 最近一次考试结果
- 收藏题目

学习数据只保存在本机服务器，按账号和题库分别组织。

## 十一、本机服务端

建议技术方案：

- React + TypeScript：用户界面
- Capacitor：Android APP
- Node.js + Fastify：服务端接口
- SQLite：业务数据库
- systemd：Linux 服务管理
- frp：内网穿透

优先原生 Linux 安装，不强制使用 Docker。

本机管理界面包含服务状态、账号管理、题库管理及数据维护四个模块。

## 十二、数据安全及备份

数据库存储在本机磁盘，公网 frps 不保存业务数据库。

支持自动备份、手动备份及备份恢复。

备份包含题库、账号信息、作答记录、错题状态、考试历史和配置。

升级程序时不能覆盖用户数据。

题库修订要保留历史试卷所使用的题目版本，避免旧考试成绩发生变化。

## 十三、APP 发布

建立 GitHub 仓库，保存项目源码、安装说明和版本发布记录。

GitHub Releases 提供：

- Android APK
- Linux 服务端发布包
- 版本说明与更新日志

APP 安装包不得包含用户密码、数据库文件和 frp 认证密钥。

V1.0 优先支持 Android。iOS、完整离线考试、复杂自动更新机制留待后续评估。

## 十四、验收要求

正式交付前，必须验证：

1. 原始 Excel 可以准确导入 1,283 道题。
2. 多个账号的学习记录互相隔离。
3. 模拟考试准确组卷 180 道，满分 100 分，时长 90 分钟。
4. 交卷结果与标准答案匹配。
5. 错题只有在不同复习轮次连续答对两次才视为掌握。
6. 所有题型筛选和薄弱题优先复习方式正常工作。
7. 手机锁屏、关闭 APP 和断线后能够恢复考试。
8. 局域网与 frp 公网连接都可以使用。
9. 服务端重启后已持久保存的数据不丢失。
10. 可通过 GitHub Releases 安装和更新软件。
11. 能够正确备份和恢复数据。
12. 后续新增三级题库不需要重写核心考试系统。

## 十五、实施约束与待定细节

V1.0 不新增已经明确排除的 AI、教师后台、排行榜等模块。

尚未明确的细节采用默认方案，例如及格线暂设 60 分、只允许同账号同时进行一场考试、按题型分区排列试卷、普通用户不能删除正式考试记录。

现有 frp 的具体公网地址、端口、域名、TLS 配置和 GitHub 仓库的公开状态，均在部署阶段依据实际环境填写，不预先虚构。

项目以能够在真实 Linux 服务端长期运行、通过 Android APP 稳定刷题和模拟考试为最终验收目标。
