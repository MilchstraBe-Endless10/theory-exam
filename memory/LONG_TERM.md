# 长期记忆（稳定事实，不写流水账）

## 使命
面向少数人的自托管理论考试练习系统；好用、稳定、好维护，比花哨功能重要。始终以 `docs/PRD-V1.md` 为主要功能基线。

## 不能漂移的约束
- 本机 Linux 服务端是唯一业务数据存储点，手机 Android 客户端，公网复用已有 frp，保留局域网直连。
- 账号仅管理员创建，没有用户自助注册；普通用户间数据严格隔离。
- 四级考试固定：120 单选×0.5，20 多选×1，40 判断×0.5；180 题、100 分、90 分钟。
- 错题在不同复习轮次连续两次正确才进入「已掌握」，任意错题再次答错重置进度。
- Excel 原始题库 1283 道（845/38/400），有重复题干，不能按题干机械删除，也不能虚构解析。
- GitHub 做代码和 APK 下载入口，但不能随意上传用户题库、数据库、凭据。
- Git 与 GitHub 是项目开发生命周期的一部分：现有私有仓库 `MilchstraBe-Endless10/theory-exam` 是正式代码托管仓库。每阶段执行「同步检查→开发→测试→安全检查→Commit→Push→GitHub 验证→记忆更新→阶段汇报」；每次开发开始前检查本地状态、分支及远端关系并 fetch。阶段完成且验证通过后，默认以包含阶段编号和实际修改内容的提交普通推送，再核验远端 SHA 与本地一致；未完成阶段可在独立开发分支推送进度，正式验收通过后再普通合入 `main`。
- 自动 Git 同步的安全边界：远端有新提交、存在无关工作区改动、验证失败或发现安全风险时暂停并报告；禁止强推、覆盖远端历史、公开仓库、发布正式 Release，或提交题库、数据库、环境变量、账号凭据、frp 密钥、个人资料及其他敏感文件；不得删除、重置或覆盖未经确认的用户改动。每轮汇报包含 GitHub 提交链接和同步状态。
- 不做 AI、排行榜、教师后台、社交、复杂权限、云端业务数据库。
- UI 视觉基准包括桌面首页 `design/reference/dashboard-desktop-v1.png` 与手机 12 屏 `design/reference/mobile-12-screens-v1.png`；桌面首页通过验收不代表手机 12 页面已完成，手机端需单独实现并逐页视觉验收。

## 更改条件
长期事实更新必须满足至少其一：用户明确改变了需求；已有正式决策文档批准修改。任何推断、Agent 的个人偏好或临时实现方便，都不能自行升级为长期事实。改动时同时核对 PRD 与 `docs/DECISIONS.md`。
