你是本项目的工程负责人和实现 Agent。当前工作目录是我提供的“理论考试练习系统”项目根目录。请**现在开始实际开发**，不要停留在复述需求，也不要尝试一轮写完整个系统。

**先执行 P0：可运行项目骨架 + 高保真可交互首页。**

工作开始前：
1. 阅读根目录 `AGENTS.md`、`memory/LONG_TERM.md`、`memory/MID_TERM.md`、`memory/SHORT_TERM.md`、`docs/UI_SPEC.md`。按需查询 `docs/PRD-V1.md`、`docs/ARCHITECTURE.md`；确认 `design/reference/dashboard-desktop-v1.png` 可以打开。不要假设已经存在代码。
2. 只读检查当前仓库、git 状态、Node/npm/pnpm、已有源码、可用浏览器或截图工具。发现已有实现则保留并在其基础上工作；空仓库则搭建最小可维护项目。
3. 简洁说明 P0 实施步骤，然后立即编辑、安装依赖、运行并验证。不需要先征求启动本地项目的许可；涉及真实公网部署、push GitHub、使用实际密钥、修改用户已有仓库历史时再征求批准。

P0 交付要求：
- 使用 React + TypeScript 实现真实 DOM/CSS 组件，建立统一设计 Token、路由、可复用 Sidebar/Header/Card/Progress 等组件。采用清晰单体项目结构，未来可以接入 Fastify/SQLite 和 Capacitor。
- 首页布局必须对照 `design/reference/dashboard-desktop-v1.png`：左侧导航、顶部栏、欢迎标题、4个统计卡、继续练习卡、模拟考试卡、题型掌握、错题复习、最近练习表。重点匹配 1536×1024 的排布、留白、字体、线条、颜色、按钮和卡片尺寸。
- UI 的行为必须合理：导航有路由；卡片 CTA 有目标页或清楚的「开发中」状态；没有后端时应使用清晰标记的开发 Demo 数据层，不能伪造真实学习历史，默认空数据时展示空状态；不要将参考 PNG 用作网页背景。
- 针对 Android 的 390×844 视口实现初版响应式排布，至少能浏览和操作。
- 本阶段不实现题库导入、用户真实认证、真实模拟考试等业务，但要保证代码结构能在后续阶段接入，不写一次性假实现。
- 用浏览器/Playwright 启动页面，截图 1536×1024 与基准图对照，记录至少一轮差异、修正、再次截图；再验证 390×844。若当前环境没有浏览器截图工具，尽可能安装/配置，确实无法验证就如实报告。
- 至少运行 typecheck、build 和可用的基础测试；不要宣称没运行过的检查成功。
- 设置可靠的 `.gitignore`，明确忽略 `local-input/`、`.env`、数据库、备份、证书、构建缓存。
- 更新 `memory/SHORT_TERM.md`，完成 P0 验收后更新 `memory/MID_TERM.md`，未验收不得标记完成。

结束时请报告：
A. 文件变化；B. 启动地址和运行命令；C. 截图位置与对比差异；D. 真实测试结果；E. 本阶段是否达到验收；F. 下个单一任务。
