# UI 1:1 专项复核提示词

只执行视觉复核和修正，不修改考试业务规则。使用 `design/reference/dashboard-desktop-v1.png`（1536×1024）为基准，实际启动项目页面并截图相同尺寸。至少比较：侧栏宽度、标题基线、4统计卡排列、两行双列卡、按钮大小和位置、进度条、表格密度、字重/字号、颜色/边框/阴影。列出最显眼的前 10 项差异，依影响从大到小修正，然后重新截图，并说明未能达到的部分。

再检查 390×844 移动布局是否无横向溢出、可按键、能看到关键入口。所有交互保留真实可访问 DOM，不允许放入基准图作为背景，不能假造实时用户数据。按需更新 `docs/UI_SPEC.md` 的真实实现 token 与本轮记忆，不擅自做新功能。
