# P5：Android 客户端、现有 frp 联通和本机备份

在用户授权后，读取环境现有 frp 配置，不泄露任何 token，规划既有 frps/frpc 的 HTTPS 反向转发；未知真实域名/IP/端口不得编造。基于现有 React 项目通过 Capacitor 生成 Android 客户端，首次配置 HTTPS 服务器地址/安全扫码绑定、记住服务器、局域网与外网连接回退（或统一域名分流），保障登录和考试状态不变。管理接口不得暴露公网。

实现 systemd 本机运行/重启、SQLite 正确热备份/恢复以及清晰安装步骤。APK 使用 Android 模拟器或真实设备测试（若不可用说明阻塞），执行 LAN 与 frp 连接测试（需要用户提供实际环境并批准），不关闭 TLS 校验、不公开部署凭据。更新记忆，停止 P5。
